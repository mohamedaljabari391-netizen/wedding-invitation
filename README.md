# دعوة زفاف عبد الرحمن وريم

## التشغيل
فك الضغط ثم افتح `index.html` في المتصفح. تحتاج إلى الإنترنت لتحميل خطوط Google Fonts؛ بقية الصفحة محلية.

- العريس: عبد الرحمن
- العروس: ريم
- التاريخ: 21 أكتوبر 2026
- الوقت: 5:00 مساءً بتوقيت فلسطين (+03:00)

## تعديل التفاصيل لاحقًا
افتح `script.js` وعدّل القيم داخل كائن `wedding` في أعلى الملف. إذا تغيّر التاريخ، حدّث `date` بصيغة ISO مع فرق التوقيت المحلي، وكذلك `dateAr` و`dateEn` واسم اليوم.

## نشر مجاني عبر GitHub Pages
1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع الملفات الثلاثة `index.html` و`style.css` و`script.js` إلى جذر المستودع.
3. افتح Settings → Pages.
4. اختر Deploy from a branch، ثم الفرع `main` والمجلد `/(root)` واضغط Save.
5. بعد النشر سيظهر رابط مجاني تستطيع إرساله للمدعوين.

## قبل الإرسال
جرّب زر «افتح دعوتنا» وتبديل اللغة والعداد، وافتح الرابط من هاتف للتأكد من وضوحه. لا يوجد رابط خريطة في هذه النسخة حسب طلبكم.
